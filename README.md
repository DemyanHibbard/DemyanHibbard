## Other Projects
- **Distributed Toolchain Integration — National Composites Centre** — A middleware platform that automates the optimisation of engineering components by orchestrating communication between multiple simulation modules across networked machines. The system accepts a component and its requirements as input, dispatches them to simulation software running on separate servers, collects results, adjusts parameters, and iterates until the component is optimised. Built using Java and Spring Boot for the web application layer, MongoDB for parametric and non-parametric data storage, and Python for a simulation API stand-in replicating the NCC's proprietary software. Designed with security requirements in mind given the NCC's client base including BAE Systems, Rolls Royce, and Airbus. Delivered across a 20-week engagement with regular client check-ins, full technical documentation, and a live handover demo.
- **Procedural Mapping Game** — top-down game built from real-world geographic data
- **View-Invariant Fashion Image Retrieval System** — Built a deep contrastive learning system using triplet loss and CNN backbones to produce view-invariant fashion image embeddings, enabling retrieval of the same clothing item across different viewpoints — achieving a 36% improvement over the mean model through online negative mining and hyperparameter optimisation across 50 configurations on a dataset of 6,400 images.
